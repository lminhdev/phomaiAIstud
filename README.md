# Local Study AI — Groq GPT-OSS 120B

GitHub Pages-ready static site.

## Cấu hình
1. Mở `script.js`.
2. Tìm `GROQ_API_KEY`.
3. Thay `PASTE_YOUR_GROQ_API_KEY_HERE` bằng API key của bạn.
4. Commit/push lên GitHub Pages.

Model cố định: `openai/gpt-oss-120b` qua Groq.
Không còn OpenRouter Free Router, WebLLM hay localhost.

**Cảnh báo:** Groq khuyến cáo không hardcode API key trong frontend. Cách này chỉ phù hợp cho website cá nhân/private; nếu repository công khai, người khác có thể xem key trong source.
